## チェックサム — 同定できず（否定結果）

格納値 `0x4C83` (`0x32080`)。総当たりした範囲:

- `sum8` / `sum8~` / `sum16le` / `sum16be` / `xor16le`
- CRC-16: ARC / MODBUS / CCITT / CCITT-FALSE / XMODEM / KERMIT / X25 / DNP
- 開始 5 種 × 終了 4 種 × 格納語の除外あり/なし

**一致 0 件。**

もっともらしい説明は、**チェックサムの対象が 24 KiB 窓の外**（512 KiB 全体、または
別セグメント）だということです。次に必要なのは **512 KiB フルダンプ**で、
15–25 分の読み出しになります。同定できるまで、エクスポートは `NOCHECKSUM` のままです。
